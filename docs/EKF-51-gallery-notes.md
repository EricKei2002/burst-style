# EKF-51 メモ：ギャラリーの手法を借りてタイポ・レイアウト・動きを作り直す

土台は main `e1c9235`（EKF-49 の 3D 作り直し）。コンセプト（Home は宇宙、Projects / About / Contact はそれぞれの惑星、切り替えは探査船）とフォールバック・性能の仕組みには手を入れていない。

借りたのは**手法だけ**。参考サイトの見た目、コード、テンプレート、文言は使っていない。motionsites / studio.motionsites.ai は閲覧だけで、サインアップもプロンプトの流用もしていない。

### 書体（fontinlogo.com の考え方）

Web フォントは追加していない。

- **表示（見出し・作品名）**: 既存の Helvetica / Arial（`font-sans`）。black で字間を詰め、大きくする
- **計器（ラベル・状態・タグ・本文）**: 既存のモノスペース（`body` の `font-mono`）。小さく、字間を 0.08em 開ける

「名前と作品名は人が読む看板、それ以外は機械の読み出し」という意味で書体を分けた。

### 気をつけた点

- サーバーは英語で描き、ブラウザが日本語なら描画後に切り替わる。元のヒーローは固定高さで吸収していたので、新しいヒーローでも本文の列に英語の高さ（長いほう）を最小の高さとして確保し、下のカルーセルが動かないようにした（これを入れる前は Mobile CLS が 0.022 だった）
- 既存のコントラスト上書き（`.text-zinc-400` など）はそのまま。新しく作った薄い文字（駐機段階の消灯中の段）は `rgb(161 161 170)` で、ほぼ不透明の下地に対して AA を満たす
- JS なしでは `.nav-tick` を出さない（`aria-current` も付かない）。駐機窓は従来どおり畳まれる

## 残課題

- ヒーローの「概要」は PC では `/Enter` まで透明のまま場所を取る（元の挙動を残した）
- 駐機段階はポインターの時だけ「点検」になる。看板はもともとキーボードで選べないため、キーボードでは「駐機」のまま
- WebGL のコンテキストを失ったときは段階が「接近」に戻る（3D の代わりの CSS の空になるため）
